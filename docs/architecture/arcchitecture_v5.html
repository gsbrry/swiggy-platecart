Overview

The Opportunity

Swiggy solved "order food now." Nobody has solved "eat well consistently without overspending." Swiggy's Builders Club opens 18+ MCP API tools for the first time to external developers — cart-add, item search, restaurant discovery. PlateCart is the planning layer that sits on top: diet goal → weekly meal plan → 3-day restock → budget tracking. Phase 2 adds a shoppable template economy where creators publish forkable meal plans.

Phase 1  Build Now

Core Features

🎯

Onboarding — Set Your Profile Once

  • Goal: weight loss / gain / maintenance
  • Diet type: veg, non-veg, vegan, keto
  • Household size (adjusts quantities)
  • Monthly grocery budget in ₹
  • Eating-out frequency per week
  • Allergies and ingredient exclusions
📋

Weekly Meal Plan Builder

  • 7-day grid: breakfast, lunch, dinner per day
  • Each meal = a dish template from the library
  • Template auto-maps to ingredients + quantities
  • Mix home-cooking days with eat-out slots
  • Eat-out slots use Swiggy Food API suggestions
🎙️

Voice Command → Instamart Cart

  • "I want to make a salad" → ingredients mapped
  • Checks estimated inventory from last order date
  • Adds missing items to Instamart cart via MCP API
  • Cart preview screen shown before anything is placed
  • User confirms → cart populated, pays on Instamart
  • Web Speech API (browser-native, zero cost in Phase 1)
🔄

3-Day Replenishment Cycle

  • Reminder every 3 days: "Time to restock"
  • Cart built from meal plan + inventory estimate
  • User reviews, edits inline, confirms — one flow
  • Monthly spend tracker: ₹ used vs ₹ budget
  • Eat-out slots tracked separately (3×/week default)
🗑️

Smart Waste Tracker

  • Post-cycle prompt: "Did you finish everything?"
  • One-tap: All used / Some wasted / Most wasted
  • After 2+ waste events on same item → quantity reduced
  • Pattern nudge: "You tend to over-buy spinach"
  • No logging forms — one tap is all it ever asks
📚

Template Library (User-Generated)

  • Create: dish name, tags, ingredients + qty, cook instructions
  • Tags: diet type, goal, cuisine, prep time
  • Phase 1: free templates only — no payment infra yet
  • Search and filter by goal, cuisine, diet type
  • Copy/fork into your own meal plan
  • Solves recipe database problem via crowdsourcing

Phase 2  After 100 Active Users

Social Layer

Gate Phase 2 behind a hard metric: 100 users completing the 3-day replenishment cycle. If that's not hit by Week 10, stay in Phase 1. Social features without a user base are just infrastructure debt.

👥

Follow & Discover

  • Follow users → see their public templates in feed
  • Bookmark templates for later reference
  • Creator profile with all public templates
  • Trending: most forked this week by goal tag
  • "Someone forked your template" notifications
🔀

Fork with Attribution

  • Fork → creates your own editable copy
  • "Forked from @username" always shown
  • Modify ingredients for allergy / budget / taste
  • Fork tree visible on template detail page
  • Original creator sees cumulative fork count
✅

Bought X Times (Trust Signal)

  • Every Instamart cart-add tied to a template = +1
  • Shown on cards alongside fork count
  • Harder to fake than likes — real purchase behavior
  • Filter: "Most bought this week for weight loss"
💰

Paid Templates — Gate Behind Traction

  • Only for creators with 50+ forks on free templates
  • Razorpay / UPI integration for Indian market
  • Creator payout after platform fee
  • Do not build payout infra until Phase 2 social is proven
Technical

Tech Stack

Frontend
Next.js 14

App Router. Web-first, responsive. Scales to React Native later. Vercel deploys with zero config.

Styling
Tailwind + Shadcn/ui

Tailwind for layout. Shadcn for accessible, unstyled-by-default components — your design, not theirs.

Backend
Next.js API Routes

Same monorepo. No separate server in Phase 1. Upgrade only if needed — don't add complexity early.

Database
Neon PostgreSQL

Serverless Postgres. Vercel-native. Scales to zero — near-zero cost while building. Branch for dev/staging.

ORM
Drizzle ORM

Chosen over Prisma: no connection pool issues with serverless Postgres under load. TypeScript-native.

Auth
Clerk

Google login + Phone/OTP (critical for India). Free tier covers Phase 1 and 2. Faster than NextAuth.

Voice — Phase 1
Web Speech API

Browser-native. Free. Upgrade to Sarvam AI in Phase 2 for Hindi and regional language support.

Commerce Layer
Swiggy MCP

3 servers, 18+ tools. Cart-add, item search, restaurant discovery. Server-side only — keys never in browser.

Deployment
Vercel

Free tier to start. Preview deploys on every PR. Edge functions for API routes. Native Neon integration.

Virtual Team

Five roles. Each covers a real gap in this build. No overlap. Once your brain.obio.in roster is accessible, replace these with your named team using the 6-step workflow.

MCP Architecture
The Agent Architect
"The MCP gives you 18+ tools across 3 servers. Your edge is orchestrating all three in one session — that's what Swiggy's own app can't do because each vertical is siloed in their UI. Start with Instamart cart-add only. Don't build Food or Dineout flows until the Instamart loop works end-to-end with real users."
India GTM Strategy
The Distribution Lead
"You're not competing with restaurants — you're competing for an app install on a phone that already has Swiggy and Zomato. The first-session hook must show value in under 60 seconds: first restock cart built, items listed, ₹ impact visible. That's the moment. Everything before it is friction. WhatsApp entry points in Phase 2."
User Trust & Behavior
The Trust Engineer
"The agent can see what to buy. The user still needs to feel in control — especially when it's their money. Never auto-add to cart. The waste-tracking one-tap works precisely because it's one tap. Reduce every action to minimum viable friction or users will quietly stop after week two. Confirm before pay, always, no exceptions."
Content & Creator Economy
The Template Strategist
"Free templates solve your recipe-database problem without you building it. But seed the library yourself — publish 30 high-quality templates before launch. Target Indian diet goals specifically: South Indian weight-loss plans, high-protein plans for gym-goers. Generic templates won't spread. Give creators a reason to publish before there's a follower count to show them."
Monetization Pressure
The Business Skeptic
"Swiggy owns the transaction. You will not earn a cut of order value. Your money comes from the planning layer — subscription for premium features: advanced budget analytics, voice in regional languages, unlimited public templates. Define your ₹/month target before writing code. If the model depends on Swiggy's margin, this doesn't work."
Session Synthesis (Alex role)
The Decision Filter
"One decision per session. Today's: Phase 1 scope is locked — Instamart cart loop, free templates, waste tracker. Phase 2 is not being built yet. The next session decides monetization model before a single Phase 2 feature is specced. That's the sequence. Don't let paid templates creep in through the back door while Phase 1 is still being built."
