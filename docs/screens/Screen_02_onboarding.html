Dev Guide ONBOARDING
Single API call — step 5 completion only
POST /api/users/onboarding Body: { goal: "loss" | "gain" | "maintain", diet_type: "veg" | "nonveg" | ..., household_size: 1–4, monthly_budget: integer // ₹ exclusions: string[] } 201: { onboarding_complete: true } 409: Already complete
Steps 1–4: localStorage only
// Persist on every step change localStorage.setItem('ob_draft', JSON.stringify({ step, goal, diet, household, budget, exclusions })) // Clear after successful POST localStorage.removeItem('ob_draft')
users table — fields set at onboarding
goal goalEnum // nullable until done diet_type dietTypeEnum household_size integer monthly_budget integer // ₹/month exclusions text[] onboarding_done boolean // default false
Zod validation
z.object({ goal: z.enum(['loss','gain','maintain']), diet_type: z.enum(['veg','nonveg',...]), household_size: z.number().int().min(1).max(8), monthly_budget: z.number().int() .min(1000).max(50000), exclusions: z.array(z.string()).max(20) })
Prevent these before building
  • No DB writes on steps 1–4. Only POST on step 5 completion.
  • Persist all state to localStorage. Browser refresh kills JS state.
  • Return 409 if onboarding_done is true. Never silently overwrite.
  • Skip = still marks onboarding_done:true with defaults. Never leave false — causes infinite redirect loop.
  • Exclusions: validate each string against a server-side allowlist. Free-text breaks template filtering.
  • Back button on step 1: show "Exit setup?" confirmation. Don't let browser back navigate away silently.
Auth flow
  • Clerk sign-up completes BEFORE onboarding. JWT available on all calls.
  • POST route: validate auth() server-side. Redirect to /sign-up if null.
  • Clerk webhook (user.created) creates minimal row. Onboarding POST fills it.
Data privacy
  • Health goal + diet = sensitive. Exclude from Sentry and Vercel logs.
  • Exclusions: validate each item against ingredient allowlist before DB write.
  • budget never returned in unauthenticated API responses.
Swiggy DS rules for onboarding
  • Icons: SVG symbols, stroke:currentColor, 1.75px stroke-width, no fill. Color inherits from parent.
  • Selected card: icon-wrap turns orange tint bg + orange stroke. Never change icon shape on select.
  • Continue button disabled state: white fill + 1.5px orange border + orange text. NOT greyed out.
  • Progress segments: 48px wide, 5px tall, 5px gap. Orange fill, #E9E9EB unfill.
  • Check indicator in card: 20px circle, orange fill, white check icon. Only visible when selected.
  • Exclusion tags when selected: orange border + orange tint bg + orange icon. X icon replaces tag icon.
  • Step 5 (exclusions): Continue always enabled. Zero exclusions is a valid choice.
  • Step 6 (complete): Replace Continue with "Go to Dashboard". Hide skip link entirely.
