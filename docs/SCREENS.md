# Screens (v1)

| Route | Who | Purpose |
|---|---|---|
| `/` | everyone | Home: problem, plan/shop/share/copy walkthrough, Indian kitchens, popular menus, cooks, FAQ |
| `/creators` | everyone | For home cooks: why and how to publish menus, community rules, paid menus later |
| `/about` | everyone | Story, promises, contact |
| `/sign-in`, `/sign-up`, `/forgot-password`, `/reset-password` | signed out | Email + password and Google |
| `/onboarding` | new users | Diet, foods to avoid, household size, username |
| `/plan` | signed in | Week planner. Desktop 7×3 grid, mobile day view. Dish picker, eating out, copy last week, copy as text, share/publish |
| `/list` | signed in | Shopping list for today / rest of week / next 7 days, scaled to household, tick off, WhatsApp |
| `/dishes` | everyone | Planetto Kitchen library, My dishes, Community. Search + diet filter |
| `/dishes/[id]` | everyone | Ingredients, steps, add to plan, copy, edit/delete (owner), report |
| `/dishes/new`, `/dishes/[id]/edit` | signed in | Dish editor |
| `/market` | everyone | Public menus by Day / Week / Month, diet filter, sort |
| `/m/[slug]` | anyone with link | Menu page: use it (fill empty or replace), ratings, share, report, owner controls |
| `/me` | signed in | Profile, preferences, my menus, menus I've used, sign out, delete account |
| `/admin` | admins | Reports queue: hide or keep |
| `/privacy`, `/terms` | everyone | Drafts |

Old URLs (`/dashboard`, `/meal-plan`, `/templates`, `/my-templates`, `/budget`, `/cart`, `/settings`) redirect to their new homes.
